# 🏆 טורנירשת - Two-Stage Tournament Manager

אפליקציית Web מודרנית ורספונסיבית לניהול מלא של טורניר ספורט (שלב בתים, עץ פלייאוף נוקאאוט, ניהול משתמשים וסנכרון ענן בזמן אמת).

---

## 📋 מפרט הטורניר (Tournament Specifications)

1. **שלב הבתים (Group Stage):**
   - 15 קבוצות מחולקות ל-3 בתים (בית א', בית ב', בית ג') בני 5 קבוצות כל אחד.
   - לוח משחקים מעגלי מלא (Round-Robin בשיטת ברגר): 10 משחקים בכל בית = **30 משחקים בסך הכל**.
2. **אימות תוצאות קפדני (Strict No-Ties Rule):**
   - חל איסור מוחלט על תוצאת תיקו. שוויון מקפיץ התראת מערכת ומאפס את הקלט מיידית.
   - הזנת תוצאה חוקית מסמנת אוטומטית את שורת הקבוצה המנצחת בקלאס `.winner` (ירוק + גביע).
3. **טבלאות דירוג דינמיות בזמן אמת (Dynamic Standings):**
   - חישוב אוטומטי של משחקים, ניצחונות (W), הפסדים (L), נקודות זכות, נקודות חובה, והפרש נקודות (Point Difference).
   - מיון ראשי: **מספר ניצחונות (W)**.
   - מיון משני: **הפרש נקודות (Point Difference)**.
4. **עץ פלייאוף נוקאאוט (Top 8 Single-Elimination):**
   - 2 המובילות מכל בית (6 קבוצות) + 2 קבוצות מקום 3 הטובות ביותר = 8 מעפילות.
   - דירוג Seeds 1 עד 8:
     - מקומות 1 בבתים -> Seeds 1, 2, 3
     - מקומות 2 בבתים -> Seeds 4, 5, 6
     - שתי קבוצות מקום 3 הטובות -> Seeds 7, 8
   - שיבוץ למטריצת רבע הגמר: **1 נגד 8, 4 נגד 5, 3 נגד 6, 2 נגד 7**.
   - קידום אוטומטי של המנצחות לחצי הגמר, לגמר, והכתרת האלופה.
5. **מערכת הרשאות (Role-Based Personas):**
   - **Viewer:** צפייה בלבד (שדות קלט וכפתורי עריכה חסומים).
   - **Admin:** הזנת תוצאות, ייצור לוח משחקים ונעילת פלייאוף.
   - **Owner:** גישה מלאה כולל טאב ניהול משתמשים ואיפוס טורניר.
6. **ייצוא ל-Excel / גיליונות אלקטרוניים (CSV Export):**
   - הורדת קובץ CSV מלא עם כל טבלאות הדירוג, תוצאות 30 משחקי שלב הבתים ונתוני עץ הפלייאוף.
   - קידוד ייעודי ב-UTF-8 עם BOM (`\uFEFF`) לתמיכה מלאה וחלקה בעברית ב-Microsoft Excel וב-Google Sheets.

## 🚀 מדריך העלאה ל-GitHub (Git Push Guide)

אם ברצונך להעלות את הפרויקט למאגר GitHub חדש, עקוב אחר הצעדים הבאים בטרמינל (Terminal):

### שלב 1: יצירת מאגר ב-GitHub
1. היכנס לחשבון שלך ב-[GitHub](https://github.com) ופתח מאגר חדש: [github.com/new](https://github.com/new).
2. תן שם למאגר (לדוגמה: `two-stage-tournament-manager`).
3. בחר **Public** או **Private**.
4. **אל תסמן** את התיבות "Add a README file" או ".gitignore" (הם כבר קיימים בפרויקט).
5. לחץ על **Create repository**.

### שלב 2: הפעלת פקודות Git בתיקיית הפרויקט
פתח את הטרמינל בתיקיית הפרויקט והרץ:

```bash
# 1. אתחול מאגר מקומי
git init

# 2. הוספת כל קבצי הפרויקט
git add .

# 3. ביצוע Commit ראשון
git commit -m "Initial commit: Two-Stage Tournament Manager"

# 4. קביעת הענף הראשי כ-main
git branch -M main

# 5. קישור המאגר המקומי למאגר ב-GitHub (החלף ב-URL של המאגר שלך)
git remote add origin https://github.com/<YOUR_USERNAME>/<YOUR_REPO_NAME>.git

# 6. העלאת הקוד ל-GitHub
git push -u origin main
```
